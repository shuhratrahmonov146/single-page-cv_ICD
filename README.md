# Single Page CV

A minimal, single-page HTML resume/CV.

## Contents

- [index.html](index.html) - the CV markup (currently placeholder content)
- [favicon.svg](favicon.svg) - site favicon

## Usage

1. Open [index.html](index.html) in a browser to preview.
2. Replace the placeholder content:
   - Name, title, and contact details in `<header>`
   - Skills list
   - Education entries
   - Experience entries (achievements and skills per role)
   - Links under "Across the Internet" (LinkedIn, GitHub, etc.)
3. No build step is required - it's plain HTML.

## Notes

- No CSS is currently included; styling can be added via a `<style>` block or a linked stylesheet.
